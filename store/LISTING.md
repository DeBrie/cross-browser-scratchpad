# Store listing copy

## Name

Cross-Browser Scratchpad

## Short description

Local-first Markdown notes with optional end-to-end encrypted sync across browsers.

## Full description

Keep a global scratchpad, a note for the current site, and an ephemeral note for the current browser window. Write Markdown, switch to a clean preview, and pin the workspace to Chrome's side panel when you need it.

Cross-Browser Scratchpad works fully offline and without an account. Optional sync encrypts global and site notes on your device before sending them to the sync service, so the server never receives readable note text. When notes differ on first sync, both versions are preserved rather than silently overwritten.

## Privacy disclosure

If you choose to enable Sync, the extension sends an opaque account identifier, authentication material, and encrypted note records to the Scratchpad sync service solely to provide cross-browser sync. Note contents and passwords are encrypted or derived locally; ephemeral notes are never transmitted. See the repository privacy policy for details.
